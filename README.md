# GardenDT
 a digital twin to simulate the healthiness of a garden.

 in this project we have several systems working in tandem. we have an MLagent which uses the unity MLagent package aswell as a grid system to simulate a simple garden via unity and it's physics.

 We have 4 pillars which we use to determine how healthy a garden is.
 1. Water level
 2. Soil health
 3. Living environment
 4. Plantdiversity

These 4 pillars are central to our project we use them to determine wether a garden is healthy or not and to suggest what changes could help improve the health of a particular garden.

#### We have 2 modes available:

a self build mode where you can build a garden anyway you want and then it will show you how healthy that garden is,

and an AI mode where the our agent will make a garden with an optimal layout for you (we have succesfully trained an AI agent however we have not yet had the chance to allow it to make predictions on a garden made by the user.)
